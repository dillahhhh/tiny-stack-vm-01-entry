A tiny stack VM for the [make.fun bounty](https://make.fun/bounty/tiny-stack-vm-01-run-20261122). `main.ts` runs every program of a set and writes `stdout.bin` + `exit.txt`, faithful to the kit's reference VM: exact trap codes, wrapping arithmetic, step/output limits.
